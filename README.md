# Teaberry for Windows

Installers for the Teaberry desktop app. Teaberry is a free 2D online RPG; you can also play it in your browser at [teaberry.io](https://www.teaberry.io).

**[Download the latest installer](https://github.com/the-damkeeper/teaberry-desktop/releases/latest/download/Teaberry-Setup.exe)**

The app installs for your user account (no admin rights needed) and updates itself.

This repository only hosts release files. It contains no source code, and nothing here is licensed for reuse.
